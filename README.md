# Projeto de Análise de Vendas no Excel

Projeto de portfólio para praticar análise de dados no Microsoft Excel. A análise usa uma base fictícia da varejista **Vitrine Viva**, com 951 registros de vendas de 2025, para explorar receita, descontos, custos e lucratividade.

## Objetivos

- Preparar e conferir uma base de vendas.
- Calcular indicadores financeiros por pedido.
- Comparar resultados por mês, categoria, região, loja, canal e vendedor.
- Resumir os resultados em um painel para apoiar a análise comercial.

## Indicadores

- **Receita Bruta:** quantidade × preço unitário.
- **Desconto (R$):** receita bruta × percentual de desconto.
- **Receita Líquida:** receita bruta menos desconto para pedidos concluídos; pedidos cancelados ou devolvidos não entram na receita reconhecida.
- **Custo Total:** quantidade × custo unitário para pedidos concluídos.
- **Lucro Bruto:** receita líquida menos custo total.
- **Margem Bruta:** lucro bruto dividido pela receita líquida.

## Análises no painel

O arquivo reúne resumos para explorar:

- Tendência mensal de receita e lucro.
- Receita, lucro e margem por categoria.
- Resultados por região e loja.
- Comparação entre canais de venda.
- Desempenho por vendedor.

## Ferramentas e recursos

- Microsoft Excel
- Fórmulas e colunas calculadas

## Arquivo

`Projeto_Analise_de_Vendas_no_Excel.xlsx` — pasta de trabalho com a base, o dicionário de dados, os cálculos e o painel.

## Como usar

1. Abra o arquivo no Excel.
2. Consulte a aba **Leia-me** para conhecer as regras e definições usadas no projeto.
3. Explore a aba **Base_Vendas** e os resumos do painel.
4. Ao alterar a base, atualize as Tabelas Dinâmicas e confira se os indicadores e gráficos continuam coerentes.
